# MathCraft 前端

MathCraft 前端是教师、学生和管理员共用的 React 19 + TypeScript + Vite Web 应用，业务数据通过后端真实接口访问。

## 功能模块

| 模块 | 说明 |
|---|---|
| 登录 | 统一使用登录账号和密码；不提供公开注册，并提示获取账号或忘记密码联系管理员 |
| 管理员面板 | 管理员创建和维护管理员、教师、学生账号，查看平台信息 |
| 智能出题 | 对话式出题与快速出题，任务进度由后端返回 |
| 题目预览 | 题目编辑、收藏和组卷 |
| 题库管理 | 教师创建题库并按成员权限共享；学生不能创建题库 |
| 学习空间 | 沿用现有教师创建、学生加入和作答流程 |
| 组卷记录 | 教师发布试卷，学生作答并查看允许展示的结果 |
| 个人中心 | 维护昵称、头像和密码 |

## 快速开始

```powershell
npm ci
npm run dev     # http://localhost:5173，/api 和 /media 代理到本地后端
```

前端开发服务器由 `vite.config.ts` 配置，将 `/api` 和 `/media` 转发到 `http://127.0.0.1:8000`。账号由后端管理员创建或由后端显式初始化命令补建，前端不创建账号，也不保存业务 mock 数据。

## 目录约定

- `src/api/` 负责接口请求和响应类型映射。
- `src/components/` 按登录、管理员、题库、出题、收藏、学习空间、组卷和个人中心组织页面。
- `src/store/` 管理登录态和全局业务状态。
- `src/styles/` 保存全局样式。
