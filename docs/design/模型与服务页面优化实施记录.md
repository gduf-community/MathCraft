## 交付范围

提供方优先的左侧子导航；提供方连接实例卡片、后端目录能力筛选、配置与返回；主语言和嵌入模型的列表与详情；辅助任务分组设置行及三种模式。沿用 MathCraft 蓝白风格、草稿和正式配置分离、兼容 Profile 与引用结构。

模型发现按选择的用途使用连接覆盖地址和适配器。发现结果只描述列表接口，不表示推理或嵌入调用成功。页面仍使用无请求体应用已保存的完整目录草稿。

后端行为验证发现独立辅助任务 Profile 明确清空密钥后仍借用同提供方其他密钥的问题，纳入本次凭据语义修复；接口和持久化字段不变。

## 验证命令与环境

- 前端：`cd frontend; npm run build` 包含 TypeScript 检查。普通构建在本机 esbuild 临时文件清理阶段出现 `Access is denied`。
- 沿用已有临时验证脚本，`node --require ../.scratch/profile-settings/esbuild-memory.cjs node_modules/vite/bin/vite.js build` 通过完整生产构建；此脚本使 esbuild 使用其内存 IPC 回退，不修改源码、依赖或 node_modules。主 JavaScript 包约 689.58 kB，保留既有体积提示。
- 浏览器：真实 Chrome 加载本地 Vite 页面，在 HTTP 边界提供假设置与假模型；所有模型请求被拦截，不访问真实服务。截图与临时验收脚本位于被忽略的 `output/playwright/`，不作为运行依赖。
- 后端：逐用例隔离设置目录、本地 HTTP 假服务；测试不读取开发者配置、不使用真实凭据。
