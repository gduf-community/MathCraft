# 知识库第一批：选对资料，传完整材料

实施日期：2026-11-02。实施起点 `bc470d8`，标记 `baseline/before-knowledge-batch1-20261102`。目标以《统一知识库设计》第 10 节第一批和用户补充边界为准。

## 范围与架构

继续使用 `MathCraft.app`、正式知识库、ParseService、RAGService、LlamaIndex、embedding 绑定、解析缓存、版本目录与发布验证。MinerU 云端扫描 OCR 策略保持现状，没有安装 OCR 模型或增加隐式本地回退。

远端已统一主包为 `backend/MathCraft/`，运行数据根为 `MATHCRAFT_HOME`。新变量指向原 home 即读取原 `data/`；没有旧变量回退，不搬迁或删除旧数据。

## 检索与资料检查

- `rag/evidence.py` 集中实现范围规范化、来源检查、版本内证据单元和完整证据选择。
- `document_keys=None` 表示普通全库；`[]` 是空范围，直接返回空 sources；空字符串、绝对路径、父目录或越界路径拒绝，不扩大范围。
- 只有 LlamaIndex 声明已支持严格文档范围。能力门禁先于模型绑定与检索运行；PageIndex 保留工具循环要求，其他引擎的普通全库行为保留。
- `GET /api/knowledge-bases/{kb}/document-readiness` 返回文档状态、来源摘要、兼容索引版本、解析身份和警告，不返回教材正文。不把 raw 文件存在当作已索引。
- 普通查询、题号查询及精确检索不可用后的回退共用范围与兼容版本。向量和 BM25 在召回前取同一允许语料，报告实际模式及 BM25 降级。
- TXT / MD 等普通文本不要求 PDF 页面状态。来源删除或替换后返回具体失败，新索引的全库检索排除失效来源。
- 候选版本验证来源及持久化索引后才发布。重建入口不会因存在旧向量而跳过证据身份升级或来源变化。
- 旧索引缺少证据身份时，普通兼容查询仍可用；增量追加需先完整重建，避免只发布新增资料而使旧资料从语料范围中消失。缺字段、节点与证据身份不匹配均明确要求重建。
- 一次出题在内部固定已检查的兼容索引版本，多个题型及题号回退不会自动切到另一个版本；公开请求不增加版本选择参数。

## 完整证据

每个发布版本保存 `evidence_units.json`，这是索引派生产物，不是另一套文档注册表。单元保留原文、文档相对路径、SHA-256、解析身份、块标识、零基 PDF 页码、图像引用、完整性与警告。增量版本保留未替换资料的单元。

当前完整单元采用整份已解析文档，确保召回节点切分不会丢失续页条件。代价是大型教材可能超预算；本批明确要求缩小资料范围，不宣称已有可靠章节或完整题目切分。不得把解析完成或 `complete` 当作原题结构、OCR 或数学质量已经通过。

题号查询可连接已定位文字、公式和表格，使用与版本一致的已完成解析缓存。边界仍是启发式，完整性为未知，不能直接作为严格生成证据。找不到题号不代表原书没有该题。

`content` 用于展示摘要，`evidence_text` 用于完整原文；题号的 200 字来源和普通来源的 6000 字符限制已移除。出题仅读取 sources 中的来源原文，不采用引擎生成的 answer。

第一层预算为完整单元合计 24000 字符；生成前再按已配置模型上下文减去输出预算和预留量检查，使用 UTF-8 字节数作保守输入上界。预算不足时减少整单元并记录原因；单个单元仍不适配则明确失败，不切片继续生成。图示未进入当前文本模型、图像引用缺失、未识别或未定位页均标记限制，严格出题拒绝。

## 逐题来源与最小保存

模型每题只返回 `evidence_ids`。服务端校验其属于本次实际提供的允许证据，拒绝缺失、未知、越界编号及模型自行提供的定位或关系。来源摘要、版本、页码与访问地址来自可信记录。

Question 增加兼容字段 `sources` 与 `review_status`。变式使用 `variant_reference`，全新题使用 `concept_reference`。原题结构及数量未知时返回 `exercise_analysis_unavailable`；本批不会生成并标注“已确认原题”。生成结果初始为 `unreviewed`，没有承诺数学正确性。

生成完成后保存于 `data/questions/<id>.json`，提供：

- `GET /api/questions`：读取已保存题目。
- `GET /api/questions/{id}`：读取题目与来源快照，重新核对原文件身份。
- `PUT /api/questions/{id}`：仅编辑允许的题目字段，禁止改写证据身份与定位。

题干、选项、答案、解析、题型或知识点改变后，状态为 `edited_requires_review`，参考证据保留。分值等非数学字段编辑不会取消已有复核标记。旧题缺少来源时保持空来源与 `legacy_unknown`，不从旧书名猜页码。

前端启动读取已保存题目，每题“来源与审核状态”展示原文、原页及图像入口。打开来源时刷新身份；核对中或刷新失败时不沿用缓存的“有效”结论，也不提供原文件、原页及图像链接。再次打开核对成功后清除旧错误，迟到响应不能覆盖新请求。来源失效时保留旧原文，阻止将当前文件冒充旧来源。原文件链接携带摘要，替换后服务端返回 409；PDF 原页和图片沿用既有校验。

收藏、组卷和学习空间继续使用原演示机制；“移出预览”只影响当前视图，保存的题目和来源仍可重新读取。本批不新增发布、收藏持久化或题目版本系统。

## 业务失败与槽位

`/api/generate` 的业务失败返回 HTTP 422，`detail={kind,message}`。`/api/chat` 的资料或生成业务失败返回 `done=false`、空 questions、`error_type` 与可读 reply，并保留已确认槽位，允许修复资料或调整来源模式后继续。缺少题型数量等信息仍先追问，不能由模型补默认数量。

普通无命中是空 sources；出题无可用参考为 `no_match`。其他原因包括 `invalid_document_scope`、`document_scope_unsupported`、`document_not_indexed`、`index_provenance_unavailable`、`source_missing`、`source_changed`、`evidence_incomplete`、`evidence_budget_exceeded`、`invalid_evidence_reference` 和 `exercise_analysis_unavailable`。

### 浏览器与真实 HTTP 链路复核（2026-11-02）

通过浏览器实际操作 React 页面，连接真实的 `MathCraft.app` HTTP 服务；embedding 与 LLM 指向本机假服务，使用 `.scratch/` 中独立的临时 home，不写原 home，不调用真实账号。以下是功能链路验证，不是模型质量评测。

- 正式 API 上传、索引两份有相同题号的 TXT。页面只选 A 文档进行参数出题，来源仅包含 A，6523 字符参考原文和末尾条件保留，假 LLM 确认收到末尾条件。
- 只选 B 文档进行对话出题。原题模式明确提示结构和数量未确认，随后改为变式可继续生成，来源仅包含 B。与自动测试一起覆盖业务失败后的槽位保留。
- 缺图与超预算资料分别显示具体业务失败，没有继续生成或截断原文。旧题页面显示来源与审核状态未知。
- 页面编辑题干、答案和解析后保存，审核状态变为需重新审核。刷新页面并停止、重启后端后，3 道隔离题目仍在，编辑值和来源保留。
- 替换 A 原文件后，回查 API 和页面均识别来源变化，旧文件地址返回 409；保存的证据原文仍含原末尾条件，失效文件链接隐藏。
- 停止后端以及临时使隔离题目快照不可读，复现来源刷新失败。原实现仍显示缓存的“文件身份有效”及链接；修复后显示未验证并隐藏链接。同一面板恢复读取后清除旧错误，恢复有效入口。
- 批量操作原确认框误称永久删除，而实际只移出当前预览。按钮及确认框已统一为“移出预览”，说明保存记录保留、刷新可重读；浏览器检查对话框后取消，没有删除题目记录。

来源状态问题在真实浏览器断言中先失败、修复后通过；仓库尚无前端浏览器测试框架，这次没有新增自动运行的前端回归用例。验收脚本和截图保留在被 Git 忽略的 `.scratch/` 调试目录。后续复核：`npm run typecheck`、`npm run lint` 和 `npm run build` 均通过，保留上述既有警告；知识库 20 项后端验收再次通过。

## 本地浏览器人工验收

1. 将 `MATHCRAFT_HOME` 配成原 home，执行 `python -m MathCraft`，再启动前端 `npm run dev`。端口沿用根 `.env`，默认后端 8000、前端 5173。
2. 在设置的正式“知识库连接”建库，准备两份不同目录下的 TXT / MD 小资料。配置可用 embedding 和 LLM 后入库；真实配置会导致真实服务调用，应由管理员明确选择和执行。
3. 选其中一份资料，确认文档状态。参数出题和对话出题均只使用该文档，来源含版本、摘要及完整原文。
4. 修改题干或答案并保存，看到“数学内容已编辑，需重新审核”，来源保留；刷新页面、重启后端后仍能读取同一题及来源。
5. 原文件替换后，来源显示变化，旧原文件地址返回 409；删除后显示不可用。仅保留旧书名的题显示来源未知。
6. 原题模式得到结构 / 数量未确认的业务提示；超长、缺图和未索引资料有具体失败，对话已确认槽位保留。
