# 运维后台出题入口接入

状态：**甲第二批实际入口接入已实现，并已与乙 V2 查询在本地整合；前端 V2 已隔离联调，部署待验收。** 当前整合验收见[整合记录](../implementation/运维后台本地整合验收.md)，本文维护入口状态、事务与异常契约；历史实测仅在该整合记录维护。

## 目标与范围

将同步参数化、后台参数化与实际对话出题接入同一运行台账。继续使用普通 OpenAI/Chat Completions，不引入 SDK、正文追踪、质量统计或复杂清理。台账字段沿用 [运行台账基础](运维后台运行台账基础.md)。

## 实际受理与事务

- 同步参数化：资源、凭据及参数校验成功后，HyDE 与生成前独立记录 accepted、running。
- `/start`：鉴权、资源复核和 SQL 任务门禁通过后，任务和台账 accepted 在同一事务提交，再缓存进度和注册后台任务；后台实际开始才写 running。显式传递同一 run_id，Phoenix 后台根 span 复用该 ID；扩展关闭时台账照常使用。
- 对话：仅快速出题与创新命题取得有效生成参数、决定生成时调用受理回调。澄清、模式切换、答疑、数据管理不建出题运行；同会话各轮独立。
- `persist_batch` flush 批次和题目，并让 completed、batch_id 和保存数量参与调用方事务。后台任务的完成状态与批次同事务提交；对话的两条消息、会话状态、批次及台账同事务提交。提交成功后的 Redis 或取消请求失败不能覆盖已保存事实。
- 提交前明确失败且已确认回滚记 failed；开始 commit 后异常或回滚无法确认记 unknown，并通过新 Session 读取既有 SQL 事实，已 completed 的事实优先。调用方不得从异常文案猜状态。
- 对话出题没有可保存批次时，明确的失败事实与会话终态、消息在同一事务提交；提交结果不明时先回读已经保存的事实。

## 停止与未知

- 已受理后原题不足：failed/NEED_CONFIRM；后续确认后的执行另建运行。
- 对话生成或审核后没有可保存题目：failed/NO_PERSISTABLE_QUESTIONS。参数化沿用现行空批次保存行为，保存成功为 completed/0，不增加质量语义。
- 暂停接口只写请求标记；执行检查点确认停止且没有批次时才记 canceled。同一会话在当前单 worker 部署内串行处理，重叠消息返回 CHAT_BUSY/409；先校验账号及会话归属。
- 删除会话时，尚未确认结束的对应运行与会话删除在同一事务中记为 unknown/OUTCOME_UNKNOWN；执行器随后确认取消等事实时可继续修正该观察，不能把删除本身当作已停止的证据。
- 异常类型映射有限错误分类；未知类别为 EXECUTION_ERROR，不保存异常全文。模型 HTTP 失败与根 span 结果均不能替代业务终态。
- BaseException 执行中断和当前进程关闭时登记的在途运行记 unknown，结束时间为空；正常关闭只处理本进程登记的 ID。启动恢复要求单 worker，且没有其他共享数据库的运行实例；在标记持久任务／会话中断的同一事务，将所有仍为 accepted/running 的对话台账及关联持久任务的未终结台账记为 unknown 和 EXECUTION_INTERRUPTED。无持久任务关联的参数化台账不被扫描，仍需受控核对；没有过期扫描，Redis 过期不会改掉 SQL 状态。
- 若启动时运维台账表或恢复所需列尚不可用，跳过该表的恢复并保留主线任务、会话恢复；运维查询仍报告数据不可用。恢复记录的观察时间不会早于已保存的观察时间。
- 待异常处理修复：同步出题独立受理事务如果已经提交但回执丢失，调用方可能尚未取得 run_id，台账可能停留在 accepted，且不能由现有持久任务或会话关联恢复。记录 unknown 的数据库写入若失败，也没有持久重试机制；两种情况需要受控核对，不能仅凭异常猜测运行终态。

## 验收标准与消费

使用临时 SQLite、fakeredis、假模型和公共禁网夹具，覆盖三条路径的状态、账号/资源关联、同会话多轮、受理与执行分离、ID 连续、失败/取消/未知、批次同事务回滚和保存后的回复/进度故障；保留原接口响应，新增 CHAT_BUSY 错误同步 OpenAPI 与生成文档。

乙通过现有 SQL OpsRun 字段消费运行摘要；查询接口由乙实现，当前已在本地整合，详见[查询 V2](运维查询V2接口与查询设计.md)。README 仅保留能力及文档入口。



验收须核对三条路径的同一 run_id、账号／资源／会话／任务／批次关联，受理与执行分离、批次与完成原子提交，以及取消请求和执行器确认停止的区别。保存后回复或缓存失败不得覆盖完成事实；关闭与重启恢复须按上述单实例边界单独验证。实测批次、独立入口烟测和静态检查见[本地整合验收](../implementation/运维后台本地整合验收.md)，不以历史通过代替当前版本或部署验收。
