# 题目 Word 导出与公式呈现

状态：按 2026-11-13 主线整合实现同步；验证范围与环境限制见文末记录。

## 目标与使用范围

把题目预览中勾选的题目输出为可编辑的 Word 文档，允许调整题型顺序、答案与解析位置。
入口为 `PreviewTab/index.tsx`、`PreviewTab/ExportModal.tsx` 和 `api/exportDocx.ts`；
后端由 `api/export.py` 接收，`services/export_docx.py` 排版，`main.py` 挂载路由。
导出直接处理提交的题目内容，不创建或发布试卷，不读取题库或收藏，也不调用模型。
收藏页历史 Word／CSV 演示入口不属于此次接入范围。

## 核心流程

1. 在题目预览勾选题目，未选择时导出按钮禁用；弹窗取当前题目与已选 ID 的交集。
2. 填写文档名称，分别选择是否导出答案、解析，指定每题下方或文末集中，并调整题型模块顺序。
   初始名称为当日日期形式的试卷名称，默认包含答案与解析，位置为每题下方。
3. 前端通过现有认证会话提交题目，下载返回的 DOCX Blob，成功显示下载提示，失败显示错误。
   导出中禁用重复提交，成功关闭弹窗。
4. 后端按 `type_order` 分组，组内沿用提交次序，只输出存在题目的题型，全卷题号连续。
   文末模式分别集中输出“参考答案”和“解析”，各项编号对应正文题号。

## HTTP 与数据契约

`POST /api/export/docx` 要求有效登录，使用 `get_current_user`；当前没有教师角色专属限制。
接口转换请求内内容，不根据题目 ID 读取资源或判断其归属。完整入口见根 `openapi.json`
及 [API 文档](../api.md)。

| 字段 | 当前约束与默认值 |
| --- | --- |
| `title` | 必填，1–120 字符；前端输入最多 80 字符，禁止纯空白提交；后端去空白后为空时使用“试卷” |
| `include_answer` | 布尔，默认 `true` |
| `include_analysis` | 布尔，默认 `true` |
| `placement` | 默认 `inline`，支持 `inline` 和 `end`；其他值返回 `EXPORT_BAD_PLACEMENT`／400 |
| `type_order` | 必填，1–6 个 `QuestionType`；前端提交所有已选题型，每种一次 |
| `questions` | 必填，1–200 个现有 `Question`，包含题型、题干、选项、答案与解析等字段 |

题型为 `single`、`multiple`、`judge`、`blank`、`compute`、`essay`。服务端当前只按
`type_order` 中的题型分组；未列入的题型不会输出，调用方应提交完整且不重复的题型顺序，
服务端未另设完整性和去重校验。列表长度、字段类型或枚举不合法由请求校验拒绝。

成功返回 `application/vnd.openxmlformats-officedocument.wordprocessingml.document`，
`Content-Disposition` 使用 UTF-8 编码的 `.docx` 文件名，`Cache-Control: no-store`。
前端优先读取响应文件名，否则使用所填标题；导出完成后回收临时对象 URL。

## 排版、公式与依赖

正文默认宋体小四（12 pt），居中大标题三号（16 pt）加粗，题型与文末节标题四号（14 pt）加粗。
输出题型名称、连续题号、题干与选项，以及按开关选择的答案和解析；不输出难度、分值、
蓝图、自检或审核明细。浏览器公式样式不决定 Word 的排版。

Word 公式以 `$...$`、`$$...$$` 识别，经 `latex2mathml` 转 MathML，再由 `mathml2omml`
转为 Word OMML。跨行展示公式在按换行拆正文段落前先压为一行，公式内部换行替换为空格。
转换失败保留带定界符的公式文本，继续导出，不能承诺所有 LaTeX 环境均可转换。
请求题目先通过现有 `Question` 规范化常见反斜杠定界符与代码栅栏。

依赖由根目录和 `backend/` 各自的 `pyproject.toml`、`uv.lock` 管理：`python-docx`
负责文档，`latex2mathml`、`mathml2omml` 负责公式；`json-repair` 供生成和审核链路修复 JSON。
使用对应环境前同步依赖，无需安装 Microsoft Word 或访问外部模型。

前端 KaTeX 全局字号调整为 `1em`；限宽横向滚动规则只作用于助手回复 `.chat-answer`，
题目预览不套用该滚动样式。现有 `Latex` 组件兼容美元及反斜杠的行内、展示定界符，
不能将模型提示词中“仅美元定界”的输出要求写成浏览器只支持美元定界。

## 异常边界与验收标准

- 未登录按现有认证流程拒绝；合法登录仅转换提交内容，不新增资源读取或保存行为。
- 空题目、超过 200 题、非法题型或位置应拒绝；关闭答案和解析后只输出题目正文。
- 覆盖多题型换序、组内顺序、连续题号，以及每题下方／文末两种排版和独立内容开关。
- 用本地文档检查标题与正文字体、可转换公式的 OMML、跨行展示公式及失败时保留文本。
- 使用隔离测试与模型替身核验生成／导出边界；不把历史审核耗时或离线界面结果当成本次实测。
