# 模型配置来源与普通知识库流程

## 目标

第一阶段在后端完整支持 DeepTutor 模型配置模块的核心使用面：`llm`、`task`、`embedding`；同时确保默认 LlamaIndex 知识库能够完成普通文档的建库、上传、解析、索引和检索。模型配置通过 `.env` 初始化，也可通过 `/api/settings` API 保存运行时 `model_catalog.json`。

## 配置来源与优先级

运行时采用以下优先级：

```text
已保存的 model_catalog.json > shell 环境变量 > .env 文件 > 内置默认值
```

`load_project_env()` 使用 `override=False` 加载 `.env`，因此 shell 中已有的同名变量优先。`.env` 只在目标 `model_catalog.json` 不存在或为空时生成初始 catalog；catalog 一旦存在，即使是用户明确保存的空 catalog，也不能在重启时被 `.env` 重新覆盖。`/api/settings/draft` 与 `/api/settings/apply` 负责脱敏、草稿、应用和运行时客户端缓存重置。

第一阶段环境变量：

- `LLM_*`：主模型 Provider、模型、密钥、Base URL、API 格式和 API 版本。
- `TASK_*`：任务模型的同一组字段；`TASK_MODE` 支持 `inherit`、`profiles`、`reference` 三种模式，默认使用 `profiles`。
- `EMBEDDING_*`：嵌入 Provider、模型、密钥、Base URL、API 格式、API 版本和维度。

API 返回的密钥是掩码值，保存时由后端恢复原值；真实密钥不会跨 API 边界返回。

## 启动初始化与路径生命周期

适用范围为统一应用 `MathCraft.api.main:app`、兼容应用 `math_q_agent.api.main:app` 和命令行启动入口。

- 导入应用模块仅装配路由和声明中间件，不加载 `.env`、创建运行时设置、导出环境变量或安装日志处理器；OpenAPI 导出不需要启动服务。
- ASGI lifespan 启动时依次加载仓库 `.env`、初始化缺失设置、导出运行时环境、配置日志并安装进度事件端口，完成后才标记 ready。命令行在解析监听参数前读取 `.env` 和有效的启动设置，保留 `--port` > shell / `.env` > 已保存 `system.json` > 内置默认值的端口优先级；该显式启动步骤可能初始化 `system.json`，其余运行时设置仍由 lifespan 初始化。
- 两个应用的 CORS 参数均在运行时初始化完成后读取，支持 `CORS_ORIGIN` / `CORS_ORIGINS`；默认无认证模式保持跨域放行。
- 配置读取通过路径服务解析默认目录，显式传入的路径继续生效；不再以配置模块导入时的 `PROJECT_ROOT` 或 `CATALOG_PATH` 快照作为默认来源。已经创建的服务实例仍归属于创建时的目录。
- 本次不增加运行中的 home 切换接口，不恢复上游多用户功能，不改变 HTTP、WebSocket 或模型目录的数据契约。

启动初始化失败应直接使 lifespan 失败，不报告 ready，也不吞掉错误。验收需覆盖应用导入无运行时写入、导入后指定 home 的启动、CORS 读取启动配置、默认路径解析，以及现有设置、解析和索引回归。

## 普通知识库流程

### 前后端部署配置

前后端共同读取仓库根目录 `.env`，部署参数由环境注入并提供缺省值。后端默认 `BACKEND_HOST=127.0.0.1`、`BACKEND_PORT=8000`；Vite 默认 `FRONTEND_HOST=127.0.0.1`、`FRONTEND_PORT=5173`。Python 默认端口集中在 `runtime/env.py`，启动设置与系统设置共用；既有 `system.json` 仍作为无环境覆盖时的兼容来源。

shell 变量优先于 `.env`；命令行 `--host` / `--port` 优先于环境。前端默认同源访问 API，开发代理由后端地址和端口推导；浏览器公开地址通过 `VITE_API_BASE_URL` 指定，修改后需重新构建。只有 `VITE_*` 可以进入浏览器构建，后端凭据不得使用此前缀。

统一配置的启动入口为 `python -m MathCraft`。直接执行 `uvicorn ... --port 8000` 时，Uvicorn 在应用 lifespan 之前解析监听参数，后续读取 `.env` 不能修改端口；不得通过修改 `.env` 迁就遗留的启动参数。联调验收必须对前端代理实际发送请求，核对其目标与后端监听一致，不能只检查默认常量或使用独立假服务。

开发与预览均代理 `/api` 和 `/ws`，后者启用 WebSocket 升级；`FRONTEND_PROXY_TARGET`（默认空）可覆盖内部 HTTP 目标，`VITE_WS_BASE_URL`（默认空）允许 WebSocket 单独部署，未设置时跟随 API 地址或页面源并自动转换 WS/WSS。预览端口由 `FRONTEND_PREVIEW_PORT` 指定，默认 `4173`；端口非法时 Vite 报错，端口占用时沿用 Vite 自动尝试后续端口的行为。URL 生成集中在 `frontend/src/api/urls.ts`，根目录位置由 Vite 配置文件路径解析，不依赖启动工作目录。后端监听通配地址时，内部代理连接回环地址。

缺少 `.env` 或变量时使用默认值，不因缺少部署配置阻止启动；启动配置的行为验收覆盖真实临时 `.env`、shell 覆盖、命令行优先、既有系统端口以及无 `.env` 默认值。测试使用隔离数据根及假的 Uvicorn 启动，不接触开发者凭据或外部服务。本次不修改 HTTP 请求响应和 WebSocket 消息格式。

### 建库与索引

1. 客户端调用 `POST /api/knowledge-bases`，默认选择 `llamaindex` 创建知识库，可在同一个 multipart 请求附带文档。
2. 解析引擎通过 `GET/PUT /api/settings/document-parsing` 选择 `text_only`、`docling` 或 `mineru`；解析器采用惰性加载，缺少可选依赖时通过 readiness 状态报告不可用。
3. 上传接口将原始文件写入知识库 `raw/`，后台任务完成解析、切分、嵌入和索引，并返回 task id。
4. 客户端通过 `GET /api/knowledge-bases`、`GET /api/knowledge-bases/{kb}/files` 和任务流接口读取状态、文档列表与索引进度；检索接口使用 LlamaIndex 索引和已绑定的 embedding 配置。
5. 扫描型 PDF 的云 OCR 遵循后端安全策略，必要时要求 MinerU Cloud 配置；Docling 和 MinerU 是可切换解析引擎，普通过程不会默认串联两者。

## 接口与数据契约

- `GET /api/settings`、`GET /api/settings/catalog`：返回脱敏后的 model catalog。
- `PUT /api/settings/draft`、`POST /api/settings/apply`：保存并应用模型配置。
- `POST /api/settings/test-provider`：测试当前 Provider Profile。
- `GET/PUT /api/settings/document-parsing`：读取和切换活动解析引擎。
- `GET/POST /api/knowledge-bases`：列出或创建知识库。
- `GET /api/knowledge-bases/{kb}/files`：读取 raw 文档列表。
- `POST /api/knowledge-bases/{kb}/upload`：上传文档并异步索引。
- `GET /api/knowledge-bases/tasks/{task_id}/stream`：读取后台任务日志流。
- `POST /api/knowledge-bases/{kb}/query`：检索已索引内容，并可选调用 LLM 生成答案。

## 异常边界

- 无 `.env` 且无 catalog 时，服务生成空的默认 catalog；调用方必须通过 `/api/settings` 配置模型。
- catalog 已存在时，环境变量变化不会覆盖已保存的 Provider、模型、密钥或嵌入维度。
- Provider 测试失败只返回错误，不会写入运行时 catalog。
- 解析器不可用、embedding 缺失或绑定变更时，后端拒绝索引并返回可读错误。
- PageIndex 仍属于后续阶段，第一阶段不把其 `reasoning.py` 假设为普通 LlamaIndex 流程的一部分。

## 验收标准

- 新运行时目录能从 `.env` 生成 `llm`、`task`、`embedding` 三个可编辑 profile。
- 已保存 catalog 的模型和密钥不因 `.env` 改动而变化。
- `/api/settings` 能读写脱敏后的 Provider、模型、活动选择、API 格式和 API 版本。
- `/api/knowledge-bases` 能创建 LlamaIndex 知识库，上传文档并返回后台 task id。
- Docling/MinerU 通过活动解析引擎切换，普通流程不隐式串联两个解析器。
- 不把真实密钥写入样例、文档或测试。
