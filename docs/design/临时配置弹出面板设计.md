# 临时配置弹出面板设计

- 日期：2026-10-29。
- 状态：已实现并完成本地验收。
- 依据：用户确认统一处理临时表单，并采用下述关闭、未保存和提交规则。

## 目标与使用范围

新建知识库、更改知识库引擎绑定、新增语言模型、嵌入模型和独立任务模型时，打开居中配置面板，避免将表单展开在页面底部。模型详情编辑、知识库引擎和文档解析等完整设置页保留页面布局。截图仅作为布局与交互参考，不增加工作区、关联已有知识库等额外能力。

## 核心流程

1. 点击新建或临时配置入口，显示居中面板及遮罩；保持原列表与滚动位置，焦点移入面板。
2. 标题、关闭按钮和底部操作栏固定；长表单仅在内容区域滚动，小屏幕适应可用视口。
3. 取消、右上角关闭和 Esc 走相同关闭逻辑。有未提交修改时确认是否放弃，拒绝放弃则继续编辑；点击遮罩不关闭。
4. 提交期间禁止重复提交和关闭；请求失败时在面板内展示错误并保留输入。
5. 新增模型保存成功后关闭面板并选中新模型。知识库建库请求成功后关闭面板，在原列表展示后台任务提交信息和后端返回的状态；任务提交不表示索引已就绪，沿用手动刷新状态流程。
6. 关闭后焦点回到原入口。Tab 与 Shift+Tab 保持在面板内，背景区域在面板打开时不可操作。

## 接口与数据契约

沿用现有知识库、引擎绑定和直接模型配置接口及字段，不修改后端与 OpenAPI。共享 ConfigurationDialog 只负责展示、焦点、遮罩、滚动和关闭请求，各业务表单负责未保存判定、提交状态与错误。

模型配置仍按当前项保存，打开或取消新增表单不得丢弃其他模型的本地编辑。完整引擎配置仍从快捷入口进入原设置页，沿用已有离开提醒。

## 异常边界

- 未读到引擎或嵌入目录时，保留现有错误与可用性限制；不自动猜测配置。
- 引擎绑定读取失败仍可关闭或取消；变更绑定保留现有确认及索引重建提示。
- 模型保存已写入但读回失败时保留已有“待核实”语义，不能视为可无条件重试的全量失败。
- 新建表单的放弃判断仅覆盖该表单；其他模型的本地修改必须保留。
- 仅使用假服务与假配置执行交互验收，不访问真实模型服务。

## 验收标准

- 三类入口均显示原生模态对话框，不再在底部展开临时表单；现有模型详情布局保持。
- 桌面与窄屏无横向溢出，长表单内容可滚动且操作按钮可见。
- 遮罩不关闭；Esc、关闭和取消一致；确认放弃之前数据不丢失。
- 键盘焦点受控，关闭后返回入口；提交期间不能关闭或重复提交。
- 创建失败保留输入与错误；创建成功关闭并更新原页面状态。
- 新增模型与其他模型草稿隔离，取消新增不影响其他项。
- 运行前端类型检查与构建，并通过假 API 浏览器交互验收；本次不改后端。

## 验收记录

- 前端 `npm --prefix frontend run build`：类型检查与生产构建通过。首次使用系统临时目录遇到 Windows esbuild 清理文件访问被拒绝，改用仓库内已忽略的 `.tmp/esbuild` 后构建成功。构建保留原有单包体积提示。
- 假 API + Chromium 浏览器验收通过：知识库新建与绑定修改、三类模型新增、空白取消、修改后拒绝放弃、Esc / 取消 / 关闭、遮罩不关闭、提交期间禁止关闭、失败保留输入、成功关闭、模型选中与跨项编辑保留。
- 焦点验证覆盖打开时进入输入框、Tab / Shift+Tab 首尾循环、关闭后返回入口；原生 Tab 可能移到 BODY 的边界已通过显式首尾循环处理。
- 1280×720 桌面与 390×620 窄屏截图已检查；长表单内部滚动、底部操作栏可见，无面板横向溢出。
- 假 API 请求次数：知识库新建 2 次（失败与成功各 1 次）、模型保存 2 次（失败与成功各 1 次）、绑定写入 1 次，无重复提交；浏览器无页面运行时异常。
- 另行验证写入已成功但读回失败：面板保留输入和待核实提示；确认关闭不触发删除 API，重新读取可找回正式模型；空白新增取消不留下未保存状态。
- 本次未修改后端、HTTP 字段、依赖与 AGENTS.md；未执行真实模型、嵌入或索引调用。
