## 实际交付

左侧底部提供独立「设置」入口，默认打开「模型与服务 → 主语言模型」。模型设置包含主语言模型、辅助任务模型、嵌入模型、提供方与连接；辅助任务支持明显的「跟随主模型」，保留引用和独立配置模式。草稿保存、恢复、丢弃与正式应用分别反馈，未保存编辑不能误应用旧草稿；未展示服务与额外字段按原结构保留。

知识库引擎与文档解析直接保存各自配置，分别执行检查。PageIndex Cloud 和 OSS 分开映射；WeKnora、Kiwix 使用专用检查。仅在后端具备能力时显示安装或下载，通用任务与 MinerU 下载分别观察、轮询和取消。页面保留扫描 PDF 可能发送到 MinerU 云端 OCR 的说明。

个人中心只含头像、昵称、只读教师身份、任教学段及年级。后端新增 GET／PUT /api/user-profile 与 POST／GET /api/user-profile/avatar，统一入口和兼容入口均装配。资料、头像与模型目录独立持久化；头像验证内容、扩展名、MIME、大小、尺寸和静态图片要求，并重编码为 PNG。前端头像选择先预览，点击「保存资料」后顺序保存资料与头像，两项失败分别反馈。

题库管理上方新增真实知识库连接、建库与引擎入口。建库的引擎选择只作用于本次；已有就绪索引换引擎时展示真实 409，并保留原绑定。下方题库协作演示保留说明。学习空间保持未开放提示；组卷保留占位流程并明确完成的是演示。

## 验证边界与已知限制

- 所有行为验收使用隔离数据根和假凭据，模型、嵌入端点为本地假服务。未验证真实账号、第三方限流、外网稳定性或真实 GraphRAG／LightRAG／PageIndex 索引。
- PageIndex OSS 后端没有配置写 API，展示能力说明和检查，不能把该项计作表单保存成功。旧 LightRAG 整包往返测试的 skip 被保留；另用合法部分配置写入检查接口可写。
- 安装和下载任务只验证假进程，实际依赖或模型资源未安装、下载。任务为进程内状态，服务重启后不承诺恢复；取消不回滚既有安装／下载结果。
- 本机普通 npm run build 的类型检查通过，但 esbuild 读取／删除 Windows 临时文件报 Access denied。使用 .scratch/profile-settings/esbuild-memory.cjs 临时让其采用支持的内存 IPC 回退后，完整 Vite 构建成功；未修改依赖、源码或 node_modules。该文件不是生产运行依赖。最终复核还发现 node_modules/.bin/tsc.cmd 缺失，未改动依赖安装，改用 node node_modules/typescript/bin/tsc --noEmit 与 node node_modules/vite/bin/vite.js build 执行同等检查，均通过。主 JavaScript 包约 665.52 kB，仍有体积提示；本期未扩大到打包拆分。
- 学习空间学生闭环、多用户认证、角色切换、真实发布及下方旧题库协作仍不在本期交付范围。当前保持单租户教师端。
- 头像与资料是顺序独立请求：头像失败可保留已成功资料和待重试头像，不提供跨请求原子回滚。
