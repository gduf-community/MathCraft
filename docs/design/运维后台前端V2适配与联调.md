# 运维后台前端 V2 适配与联调

状态：M4 V2 适配、旧页面收缩及隔离页面联调已完成；尚未合入 main 或部署。基线为 `codex/ops-integration-v2@35faf029ccdebf89d4b96f32d13121247604cf33`。

## 目标与范围

M4 只对接已整合的三个管理员 V2 GET，保留平台资源统计、账号管理、模型与检索、账号安全。
删除依赖、异常、告警、质量统计、正文追踪和产品内演示入口。不改变后端路由、迁移、模型、权限或生成生命周期。

## 数据与流程

类型和运行时校验对齐 `backend/app/schemas/ops.py`。概览使用 total_runs、六状态计数及最多十条最近运行，列表使用 limit/offset/has_more，详情只展示 run。
数量 null 显示未知，0 显示零；completed 显示批次已保存，不证明质量或数量达标。
筛选只发送受理时间、账号、入口、状态、会话、任务及批次。时间为带时区 ISO，区间左闭右开；不添加十四天或禁止未来的旧规则。
翻页沿用实际窗口，不拼接多个页面；翻页后暂停轮询，刷新回首页。筛选或每页数量变化重置 offset。
初次默认窗口跟随服务端当前时间；显式应用的时间窗口固定在应用时刻，刷新只更新该窗口内事实。

## 错误和交互边界

区分有效空台账、401、403、422、404、503及格式错误。404只表示不存在，503不回退零记录或演示。
后台刷新失败保留旧数据并明示；无权限时清除旧结果。隐藏页面暂停轮询，旧请求取消且晚到响应不覆盖新筛选。
运行详情支持原生模态、Escape、焦点恢复。最后观测时间不当作心跳，也不由页面推断终态。

## 复现

浏览器回归的依赖安装与执行入口见[前端说明](../../frontend/README.md#可复现离线回归与-ci)。

离线页面回归在 frontend 执行 `node ops-panel-regression.mjs`，自行启动5182测试Vite并在结束时关闭。API 全部在浏览器测试边界拦截，外部网络阻断。

正式临时台账联调分两个终端：

```powershell
# 仓库根目录；解释器替换为当前测试环境。输出目录须为新目录。
.venv\Scripts\python.exe backend/tests/ops_browser_server.py --output .scratch/ops-ledger-new-case
```

```powershell
# frontend 目录；使用上一步打印的合成种子绝对路径。
$env:OPS_LEDGER_SEED = '<仓库绝对路径>/.scratch/ops-ledger-new-case/ledger-seed.json'
node ops-ledger-regression.mjs
```

页面脚本自行启动5183测试代理，只转发到种子中记录的随机回环端口；不得把种子或代理改为真实部署。完成后在后端终端 Ctrl+C 停服。辅助脚本仅导入公共测试夹具，不读取个人 dotenv、local_secrets 或文件密钥；后端禁止外部连接，浏览器只允许本任务本地来源。
