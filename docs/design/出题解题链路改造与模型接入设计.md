# 出题解题链路改造与模型接入设计

> 状态：分支能力已实现，2026-11-17 离线合并验收完成，实际模型与部署另行验收。覆盖出题两模型分工、解析精简校验、
> 提示词正例修复、检索与切分策略、答疑拒答降级、学校自部署模型接入。

## 1. 选择题两模型分工

- **出题模型**（快速模式，关闭思考）只命制题干与命题蓝图：`Question.options` 恒为空数组、
  `answer/analysis` 恒为空字符串（`schemas/question.py` 放宽为默认值，中途态合法）；
- **解题模型**（思考模式，`llm.chat_json(thinking=True)`）在审核链路最后一环
  （`question_review._solve_one`）独立解题：先解出正确答案文本，生成 3 个误导性干扰项
  （修改符号、改变数值、构造近似易错值），由**代码随机分配正确答案在 A/B/C/D 中的位置**；
  多选题解出 2~3 个正确项 + 1~2 个干扰项，同样随机分配；
- 解析精简：可省略中间代入与展开，必须保留关键步骤与关键公式；
- 解题失败的题目（无答案与解析）在 `review_questions` 末尾剔除，宁可少给不出半成品；
- 判断题选项固定 正确/错误，由代码生成；答案与解析同样来自解题模型。

影响范围：`prompts.py`（QUESTION_SYSTEM/SOLVE_SYSTEM 全部重写）、`question_gen.py`
（单题输出预算 3000→1600、judge 选项逻辑）、`schemas/question.py`、`question_review.py`
（解题层重写 + 无答案剔除）、`tests/conftest.py` 与 `test_question_review.py`、
`test_question_stream.py`（answer/analysis 不再必填）。

## 2. 解析精简与校验

- `SOLVE_SYSTEM`：解析先结论后关键步骤，结论与 answer 一致；
- 新增 `_latex_issue` / `_latex_repair` / `_polish_analysis`：解析套用与题干相同的
  LaTeX 定界校验（禁止 `\(\)` `\[\]`、$ 必须配对），违规先机械修复
  （`\(\)`→`$`、`\[\]`→`$$`），仍违规带错误重试一次，第三次失败判定解题失败；
- Pydantic：解析写入后随整题经过 `Question.model_validate` 强校验；
- 解题显式开启思考模式（`llm.THINKING_ON`），`_create` 支持 thinking 三态
  （True=开启 / False=关闭 / None=服务端默认），接口不认时自动降级。

## 3. 提示词正例修复

QUESTION_SYSTEM 正例二第 (2) 问：曲线 $y=xe^{-x}$ 与两轴围成的面积为
$\int_0^{+\infty}xe^{-x}dx=\left[-(x+1)e^{-x}\right]_0^{+\infty}=1$，原示例答案
$1-\frac{2}{e}$ 计算有误，已修复；正例一（$\frac{4}{3}$）复核无误。

## 4. 检索策略：精准检索 + 二级标题切分

- **对话查询改写停用**：对话出题不再生成与注入 HyDE 假设文本，稠密与稀疏检索均使用原始查询；其他既有参数化入口的 HyDE 调用仍保留；
- **二级标题切分**（`rag/chunking.py` 新增 `_chunk_by_headings`）：`##`/`###` 标题作为
  切分点，一节一个 chunk，章标题（##）作为其后各节的上下文前缀，`####` 与正文归属
  当前节；「目录」区域整体跳过；超长节内部滑窗兜底。练习卷题号切分保留；
  存在标题锚点（≥2 个）即走标题切分，否则回退长度聚合。

影响范围：`documents.py` 入库链路（parse 后的切片路由）、`chat.py`（HyDE 移除）。
存量文档重新解析后按新策略生效。

## 5. 知识答疑拒答降级

- `QA_SYSTEM` 改为结构化协议：先判断问题与召回材料的相关性，输出
  `{"related", "answer", "coverage"}`；相关性标准为「材料中存在能直接支撑回答的内容」；
- `qa.py` 走 `chat_json`；`related=false` 或 answer 为空时拒答——明确告知超出材料覆盖范围，
  并列出材料覆盖的章节（优先用模型给出的 coverage，缺失时从召回 chunk 的
  「文档 · 章节」汇总），引导用户就相关内容提问；
- 引用只能来自召回 chunk（prompt 硬约束 + 拒答兜底），宁可拒答不脑补。

## 6. 学校自部署模型接入

- 网关 `https://newapi.ai.gduf.top/v1`，模型 `deepseek-v41-flash-1017-w4a8`
  （原分支记录的适配测试：连通、chat_text / chat_json / chat_json 思考模式 / chat_stream 全通过；本轮合并仅使用假模型离线验证，未复测该服务）；
- **密钥不进代码仓库、不写 .env**：新增 `platform_llm_settings` 表（单行），
  API Key 以 Fernet 静态加密落库（`services/secure_store.py`），主密钥自动生成于

## 合并后的事务与取消边界

- 对话保留 main 的运行身份和统一提交门禁；模型调用前释放读事务，结果写入前重新验证账号、资源归属和当前运行身份。
- 命题、解题、审核、补齐、凭据回退和参数兼容重试均传递取消；取消不转换为普通模型失败，不继续补题或发布部分批次。
- 独立解题在字段完整且有效后更新整题；进入审核前已有完整题目求解失败保留有效旧字段。新题必须独立解题成功才交付，快速修补模型补出的答案不作为解题成功依据。
- 凭据、地址与模型按同一配置快照传递；平台保存后失效缓存，失效前开始的读取不得重新发布旧缓存。知识答疑的 JSON 重试同样绑定当前 run 的取消检查。
- 主密钥先写入独立临时文件，再发布至固定路径；并发创建只能采用同一份完整文件，已有密钥损坏不会被静默覆盖。密钥文件随 SQL 一并备份。

## 验收标准

1. 选择题的选项与答案全部来自解题模型，正确答案位置随机分布；
2. 解析含关键步骤与关键公式且通过 LaTeX/Pydantic 校验，渲染不再出现定界错误；
3. 提示词示例的计算过程与答案复核无误；
4. 教材类文档按二级标题整节召回，练习卷仍按题号切分；
5. 答疑对不相干问题拒答并提示材料覆盖范围，引用全部来自召回 chunk；
6. 自部署模型适配测试全通过，密钥仅以密文存在于本地数据库，仓库与 .env 均无密钥。
