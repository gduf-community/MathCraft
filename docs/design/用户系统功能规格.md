# 用户系统功能规格

状态：方案讨论中，尚未授权开始业务实现。核对日期：2026-11-04。

## 目标与范围

补齐教师与学生的自助注册、登录和个人资料闭环。初版仅在内部发布，服务面向个人使用者及组织相关使用者。当前实施分支为 `main`；保留 `main` 用于知识库及公共模块、`agent` 用于智能体模块的分工。

## 已确认决策

- 初版允许任何人自助注册，不设置管理员权限，不实现管理员创建、邀请或账号管理后台。此决定取代此前受控开通方案。
- 个人教师与组织知识库后续可能涉及组织管理者、教师拉取或授权；当前仅记录背景，不设计或实现多人协作与组织授权。
- 开发阶段保留默认教师、学生账号，方便切换身份验证业务。
- 开发环境登录页提供“填充教师账号”“填充学生账号”按钮；点击只填充对应示例账号密码，使用者再点击登录，经真实接口认证。
- 本次用户系统属于公共基础能力，在 `main` 开发。

## 当前实现证据

- 后端入口为 `backend/app/main.py`，用户与个人模型设置存储在 SQLAlchemy 模型中。
- `/api/auth/login`、`/me`、`/logout`、`/change-password`、`/password` 已有实现；密码使用 bcrypt，会话使用 Redis。
- `/api/users/me` 支持个人资料更新，相关子路径支持头像与个人模型设置。
- `backend/scripts/seed.py` 已提供 `teacher`、`student`、`student2` 开发示例账号，公开示例密码为 `123123`。已存在的账号跳过，不重置其密码。
- 当前脚本需要人工执行；本轮未执行初始化或连接运行数据库，不能断言本机已创建这些账号。
- 登录页表单初始账号、密码为空；刷新登录态通过 `/api/auth/me` 恢复。
- 当前没有自由注册或忘记密码恢复接口；登录页改密仍要求原密码。
- 现有状态拦截与资源权限依赖不等于已经实现管理员管理后台。

以上为源码静态核查，未作运行验收。

## 核心流程与待确认项

1. 自助注册：待确认注册字段、身份选择、重复账号处理和注册完成后的登录流程。
2. 开发登录：快捷按钮设置对应身份并填充账号密码，随后手动登录；仅开发环境显示。默认账号初始化触发方式待确认。
3. 自助注册者自行设置密码；忘记密码处理与本期范围待确认。
4. 本期不新增管理员角色、管理后台、组织授权或多人协作；现有资源归属校验继续保留。

## 接口与数据契约

本轮不新增接口或数据库字段。现有契约以根 `openapi.json` 和 `backend/app/schemas/` 为准；注册接口需在注册字段与流程确认后另行定义。

## 异常边界

- 默认开发账号不能代表生产用户开通方案；现有 seed 跳过同名账号，不能据此保证示例密码仍可用。
- 开发快捷入口应经过真实密码与角色校验，仅开发环境显示；不触发自动登录。
- 改密后的会话撤销并发、Redis 失败与禁用后重新启用的会话策略需要专项设计和验证。
- 多字段登录标识的跨字段冲突、密码输入边界及头像校验是已发现的实现缺口，修复范围待确认。

## 验收标准

- 已确认：教师与学生在开发环境均有可用的默认账号，快捷按钮只填充并由使用者手动登录。
- 已确认：内部发布的初版开放自助注册，无管理员权限；不实现组织授权与多人协作。
- 已确认：用户系统开发位于 `main`，不改变智能体模块的分支归属。
- 待补充：注册字段与身份规则、注册完成流程、密码恢复、会话撤销及默认账号初始化的可执行验收场景。
