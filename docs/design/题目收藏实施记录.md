## 2. 已完成范围

### 2.1 页面

- 左侧导航「题目收藏」接入真实页面，替换「该模块暂未开放」提示。
- 页面头部：标题、演示数据提示、收藏总数 / 覆盖知识点 / 本周新增统计、导出与组卷按钮。
- 收藏夹侧栏：全部收藏、未分类、自定义收藏夹及题量；新建、重命名、删除；删除后题目回「未分类」。

- 空状态：空收藏夹与筛选无结果两种文案与动作。
- 批量操作条：已选数、合计分值、移动收藏夹、导出提示、加入组卷、取消选择。
- 新建 / 重命名收藏夹弹窗、删除二次确认、移动收藏夹弹窗。
- 取消收藏撤销提示：5 秒内恢复题目与勾选状态。

## 3. 已知限制

- **数据为 mock**：`api/mock/favoritesMock.ts` 内置 10 道题、4 个收藏夹（未分类、导数与微分、线性代数、概率统计）。
- **刷新即重置**：收藏、收藏夹、排序与筛选状态不跨刷新保存；页面标题旁有「演示数据 · 刷新后重置」提示。
- **未接后端**：没有 `GET/POST/DELETE/PATCH /api/favorites` 等接口，也没有数据库或文件持久化。
- **组卷仅提示**：页面级、卡片级与批量条的「组卷」只累计 `pendingAssembleCount` 并提示，不打开 `AssembleModal`，不进入组卷流程。
- **编辑只读**：卡片「编辑」只提示「编辑能力待接入」，不进入编辑态，也未抽共享编辑组件。
- **导出仅提示**：Word / CSV 导出未实现。
- **部分可选增强未做**：URL query 还原筛选状态、知识点胶囊点击筛选、来源失效置灰、收藏夹排序与管理页。
- **异常态未覆盖**：mock 无加载失败、分页失败与网络重试状态。
- **响应式未逐一截图**：自动化验收在 1440 宽度完成；1280 / 1680 与 <1024 的收藏夹折叠仍需人工确认。
- **预览页星标手测前提**：当前后端未配置模型、没有知识库，无法真实生成题目；手测星标联动需先配置模型并建库，或临时把 `frontend/src/api/client.ts` 切到 `mockAdapter`（测完必须还原）。

## 4. 后续待办

### 4.1 接后端：替换 `api/favorites.ts`

`FavoritesContext` 与页面不需要改动，只替换 `api/favorites.ts` 内部实现。建议接口与设计文档第 5 节一致：

| 封装方法 | 建议接口 | 说明 |
| --- | --- | --- |
| `listFavorites` | `GET /api/favorites?folderId&type&difficulty&knowledgePoint&source&q&sort&cursor&limit` | 服务端筛选、排序与分页；返回 `{ items, total, nextCursor }` |
| `listFolders` | `GET /api/favorite-folders` | 返回收藏夹及题量 |
| `addFavorite` | `POST /api/favorites` | `{ questionId, folderId? }`，重复收藏幂等 |
| `removeFavorite` | `DELETE /api/favorites/{id}` | 前端保留撤销快照 |
| `restoreFavorite` | `POST /api/favorites/{id}/restore` 或重新 `POST /api/favorites` | 需与后端确认撤销语义 |
| `createFolder` | `POST /api/favorite-folders` | 名称必填、同名校验 |
| `renameFolder` | `PATCH /api/favorite-folders/{id}` | 名称与说明 |
| `deleteFolder` | `DELETE /api/favorite-folders/{id}` | 服务端把成员归入 `inbox` |
| `moveFavorites` | `POST /api/favorites/move` | `{ ids, folderId }` |
| `updateFavoriteQuestion` | `PATCH /api/favorites/{id}` 或由后端按 `questionId` 读取最新题目 | 避免收藏快照与题目主数据不一致 |

同时需要补齐：

- 加载中骨架、加载失败原位重试、分页游标与全部加载完提示。
- 服务端统计（收藏总数 / 覆盖知识点 / 本周新增）或明确由前端从分页数据计算。
- 来源失效：题目或来源题库被删除时置灰、不可组卷、仍可移出。
- 权限与单租户边界：收藏归属当前教师，不引入多用户行为。

### 4.2 待补交互

## 5. 本地启动与验收

### 5.1 启动

```powershell
# 后端（仓库根目录）
.venv\Scripts\python.exe -m MathCraft --port 8000

# 前端（另开终端）
cd frontend
npm run dev
```

访问 **http://127.0.0.1:5173/**，左侧点击「题目收藏」。

依赖已安装在本机 `.venv` 与 `frontend/node_modules`；当前没有 `.env`，后端未配置模型与知识库。收藏页不依赖后端即可使用。

### 5.2 验收入口

按 [题目收藏页面设计](题目收藏页面设计.md) 的「验收标准」逐项执行，重点：

1. 进入收藏页，统计为 `10 / 10 / 5`，首屏 6 张卡片，加载更多后 10 题。
2. 切换收藏夹、题型、难度、知识点、来源、搜索与排序，列表与计数同步，已选清空。
3. 全选只作用于当前筛选结果；部分选中为中间态。
4. 勾选后批量条出现，合计分值正确；加入组卷提示计数。
5. 取消收藏后 5 秒内可撤销，题目与勾选恢复。
6. 新建、重命名、删除收藏夹；删除后题目回「未分类」。
7. 空收藏夹与筛选无结果两种空状态正确。
8. 紧凑视图隐藏选项与答案解析；卡片视图恢复。
9. 刷新页面恢复初始 mock 数据。
10. 预览页星标联动需先生成题目（见第 3 节前提）。

### 5.3 构建

```powershell
cd frontend
corepack pnpm build   # 或 npm run build
```

本机没有全局 pnpm，使用 corepack 提供的 pnpm；构建会生成 `pnpm-lock.yaml`，提交前应删除，项目仍使用 `package-lock.json`。
