# MathCraft 考研数学智能出题系统总体需求文档

**状态**：总体需求基线。2026-11-21 已同步本期范围，开放的交互决策见第八节。

**首批用户**：使用数学一、数学二、数学三资料开展命题与组卷的教师。

**产品目标**：教师上传资料，在对话中说明出题要求，逐轮补齐条件，生成并审阅题目。教师可以针对一道题提出修改要求，随后选题组卷，将题目或试卷保存为可编辑的 Word 文档。

## 一、已确认需求与交付状态

| 编号 | 需求 | 当前状态或本期决定 |
| --- | --- | --- |
| R01–R02 | 面向考研数学教师，数学一、二、三及全部章节纳入产品范围 | 教师可用自然语言描述范围。考纲目录和各章节的生成质量需分别验收 |
| R03 | 教师将题目、试卷或教材上传到知识库解析后用于出题 | 已有上传、解析、入库及就绪校验 |
| R04 | 在出题对话中选择一个或多个解析结果 | 当前会话绑定单份已入库资料。多选保留为总体需求 |
| R05 | 通过对话提出和补全出题要求，向教师说明当前可用能力及限制 | 已有对话追问。本期取消初次配置面板的交付要求，能力提示方式及未来恢复条件待确认 |
| R06 | 对指定的一道题进行定向修改，并同步处理关联答案与解析 | 待实现。结果经教师预览并应用后生效，目标题目的定位方式待确认 |

## 二、资料与出题范围

1. 教师在知识库上传题目、试卷或教材，查看解析状态。解析或索引失败时，说明当前状态和可采取的操作。
2. 支持教师预览资料原文，按整份教材选择解析结果，通过对话补充章节、页码与排除范围。原文、解析结果和使用范围应具有可辨认的来源关系。
3. 多份资料共同用于一个出题任务仍是目标。资料指代不清、印刷页码与文件页序不一致、解析结果缺少定位信息或范围无法满足时，应先澄清或说明限制，由教师决定如何调整。
4. 数学一、二、三及其章节均纳入总体范围。考纲年份、目录来源、跨章节与跨知识库选择规则继续细化。章节可描述、来源可定位和题目符合范围分别验收。
5. 现阶段对话绑定单份资料，章节和页码主要通过文本约束传递。涉及指定页码或严格章节取材时，应如实说明能否确定范围。逐题的资料、章节、页码或知识点依据仍是质量目标。

## 三、对话出题与能力说明

1. 教师在对话中提出题型、各题型数量、难度、知识点或资料范围。系统沿用已有信息，只追问生成所缺的条件。
2. 已有快速出题与创新命题入口，系统生成并审核结果，必要时补题，显示实际题量和异常。新增题目进入题目预览。
3. 能力说明需要覆盖可用题型、必需条件、当前资料使用范围、可执行的后续操作，以及系统无法满足要求时教师能采取的操作。提示内容须以当前可用能力为准，功能上线后再更新示例。
4. 题型分值、总分、考查能力、按知识点新编、例题变式、错题练习、评分标准和图形输出仍按各专题的实现范围及质量标准推进。

**待确认方案**：在新对话输入框上方展示少量出题示例。教师点击「出计算题」后，输入框填入「依据当前资料，围绕定积分出 3 道中等难度计算题」。教师可以编辑这句话，再手动发送。缺项时沿用现有追问。遇到资料范围无法定位或其他未支持的请求时，在该轮说明具体限制与可行操作。以后如果教师反复录入同类结构化条件，或多题型配置经常需要澄清，再评估是否恢复可选面板。

## 四、单题定向修改

教师在审题时可以明确指定一道题，并通过自然语言要求更换题型、调整难度、修改条件或补充解析。系统应把操作绑定到那道题的身份。题目在列表中的排序或入卷后的题号可以变化。

- 修改仅作用于教师指定的题目。目标有歧义时先澄清，生成失败时保留原题内容。
- 修改涉及题干、条件、选项或题型时，要同步处理答案与解析，并重新检查受影响内容。单独补充解析也须核对解析与当前答案的对应关系。
- 修改生效后，教师可以继续按同一目标题目提出后续要求，并选用其当前内容组卷和导出。
- 现有手动编辑入口和对话重新生成可作为交互参考。单题定向修改按独立场景实现与验收。

系统先展示修改后的题干、答案与解析。教师点击「应用」后更新该题的当前内容，也可以放弃本次修改。操作入口、定位方式和预览保留方式待细化。

## 五、组卷与 Word 成果

教师在题目预览中选用题目，打开组卷弹窗调整题型模块顺序，再选择保存到组卷记录。已保存的试卷包含组卷时的题目快照。Word 下载独立生成可编辑的 .docx 文件，教师可以在本地打开、编辑和保存。产品文案使用「保存组卷记录」和「导出 Word」标明两个动作。

主要验收场景是教师从已生成的题目中完成审阅和选用，核对导出成果的题目、顺序、答案和解析。现有题目预览支持勾选题目导出 Word，并选择是否包含答案和解析及其排版位置。题目预览的组卷与导出为两个入口，各自使用提交时的选题和顺序。本期沿用题目预览下载，Word 文件由教师保存在本地。公式和版式按现有 Word 导出契约验收。

## 六、质量与异常边界

| 场景 | 目标行为 |
| --- | --- |
| 资料未就绪或范围不明确 | 说明限制，提供重试、补充资料或调整范围的操作 |
| 模型响应不完整或题量不足 | 显示实际交付数量、差额和失败原因 |
| 数学检查无法判定 | 明确展示检查结果或待复核项 |
| 单题修改失败、目标不明确或出现过期结果 | 保留已应用内容，定位目标后再处理 |
| 重试、暂停、刷新或重启 | 保留已保存成果，避免重复创建或覆盖教师已应用的内容。按对应专题验收恢复粒度 |
| Word 导出失败 | 展示错误并允许重试，教师可继续使用当前选题或组卷结果 |

数学正确性、范围符合度、资料命中率和教师采用情况分别评估。程序检查、数学工具验证、模型审核和教师复核需区分，评估样例及阈值按质量专题确定。

## 七、建设重点与验收

| 验收场景 | 通过条件 |
| --- | --- |
| 了解能力并开始出题 | 教师能从对话入口得知如何指定资料、题型、数量、难度和范围，缺项时能按追问补齐 |
| 逐轮补充要求 | 教师跨轮补充不同条件，系统按最终有效要求出题并显示实际交付情况 |
| 单题定向修改 | 教师指定第 2 题更换题型，预览中题干、答案与解析一致，点击「应用」后才更新第 2 题。放弃修改时保留题目当前内容，目标不明确时先澄清 |
| 现有组卷与 Word 成果 | 教师能选题组卷并保存组卷记录，从题目预览下载的 .docx 可以在本地打开、编辑和保存，选定题目、编号和配套内容按对应入口保持一致 |
| 多资料与原文定位 | 在对应功能交付时，能选择至少两份解析结果，辨认源资料，正确应用对话指定的章节和页码 |
| 异常与部分交付 | 资料、模型、审核或导出出现问题时显示实际状态，并为教师保留可操作的恢复路径 |

本期建设重点是能力说明与单题定向修改，并用现有组卷和 Word 导出验收教师操作闭环。多资料选择、原文预览与精确取材、质量评估及任务恢复按专题推进。教师多人协作另行规划。

## 八、开放决策

1. 能力提示的入口与频率，以及什么样的教师使用反馈值得重新评估参数面板。
2. 单题修改的题卡入口、自然语言题号定位、歧义处理和预览保留策略。
3. 多资料选择的边界、资料原文预览支持格式、考纲目录、印刷页码映射和缺失定位处理。
4. 质量评估样本、验收阈值、出题策略、恢复粒度，以及后续协作的权限和启动时机。
