# Agent 对话输入区调整规格

## 问题

选资料要离开对话输入区。正文自动折行时输入框不会跟随增长。历史会话图标无法区分模式。切换资料或会话会丢失正在编辑的文字。

## 用户交互

1. 教师或学生可从输入框左下角的「题库选择」向上展开，搜索题库并选择已就绪的文档。
2. 选择过程显示文档处理状态和空列表提示。选定文档后收起，按钮旁显示当前选中的资料。
3. 正文随手动换行或自动折行向上增高，完整展示最多三行，第四行起在输入区域内上下滚动。
4. 四种对话模式各用一个小图标。每条历史会话显示其最新已保存的模式图标，缺少模式的历史会话使用快速出题图标。
5. 同一页面中，切换历史会话或题库文档后，返回原会话时恢复该会话的文字草稿。尚无会话时按题库和文档暂存。
6. 正常发送时清空对应的文字草稿。模式切换和其他会话的操作保留当前草稿。删除会话时移除该会话的草稿。

## 接口与验证

会话列表返回已有的会话模式，值与会话详情一致。沿用现有题库与文档接口、模式存储和账号级访问校验。

从 Agent 页面验证两级选择、三行限制、会话间草稿隔离和模式图标。从会话列表 API 验证默认模式以及已保存模式的返回值。草稿只在当前登录页面内暂存，图片沿用现有生命周期。
