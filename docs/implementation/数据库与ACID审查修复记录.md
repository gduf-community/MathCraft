### 学习空间前端事实

- 主应用 `frontend/src/App.tsx` 挂载 `SpaceTab`，侧栏提供“学习空间”入口；这是真实业务入口，不是独立演示页面。
- `frontend/src/api/backend.ts` 已连接空间列表、创建、改名、解散、加入、退出、成员管理及空间试卷接口。

- 现有历史复盘依赖仍可访问的学习空间；学生组卷记录只包含本人创建的试卷。退出、被移出或空间解散后的独立历史列表，以及历次作答选择器，当前没有前端入口。这属于现状边界，不据此自动扩展本轮功能。

### 本轮实现证据（历史修复快照）

- 学习空间新增“从本空间移除”。后端 DELETE 与更新 `space_ids` 共用试卷写门禁和按空间的作答检查；有作答时保留发布关系，历史作答与教师统计入口继续有效。催交在同一门禁内刷新关闭、删除和本空间停止状态，并检查冷却时间。
- 对话数据 DSL 明确 `mode=record|paper`。默认移除组卷记录；只有明确的整卷删除请求才使用 `paper`。确认预览说明实际影响，执行按试卷 ID 排序，在同一事务内调用既有删除服务，任一失败整体回滚。
- 作答提交拒绝重复或不属于当前快照的题目 ID。前端在交卷前读取当前快照，创建作答后再次核对题目 ID；发生变化时保留匹配答案、暂停交卷并提示重新检查。作答题目使用独立的 `paper_question_id` 类型，不复用题库题目的标识契约。
- 任务受理、认领和结果提交复核原认证版本。认领阶段的初始读取、参数解析或提交异常进入一次有界故障收束；旧执行者不能释放其他运行的租约。轮询结果复核当前题库、资料、批次与题目，已删除结果不再返回缓存副本。前端临时网络或服务错误继续查询原任务，不再次提交生成。
- 题库列表为原创建者保留未完成删除记录；资料 SQL 行已清、文件尚待清时，原列表保留最少展示信息及同一 DELETE 重试入口。整库删除也必须清理此前单资料删除留下的文件，全部完成才返回 204。删除中的题目拒绝编辑或删除，SQL 清理同步移除持久任务中的题目与审核副本。
- 确认弹窗等待异步操作，失败显示原因并保留重试；处理中禁用重复确认和关闭。题库／资料删除失败后刷新最新阶段，删除中的资源不提供普通编辑、上传或下载操作。
- OCR 简化稿使用正文哈希、源 OCR 哈希及完成清单校验，正文和清单原子发布；失败不覆盖已有完整文件。HyDE 已生成的文本不会因辅助 Redis 写入失败而丢失。
- 作答、学习空间试卷、题库列表及资料列表挂载明确的响应模型，包含 `grading`、空成绩、可分别为空的开始／结束时间、删除阶段及历史状态。前端映射同步维护，OpenAPI 与完整 API 索引重新生成。
