# 领域模块与跨端协议分层

**状态**：accepted

MathCraft 后续采用领域模块与跨端协议分层：Agent、知识库、题目、设置和传输分别拥有清晰的模块接口，客户端只依赖 HTTP、SSE、WebSocket 和共享数据契约。OpenAI Agents SDK Session 负责 Agent 对话上下文；题目任务、候选、版本和确认记录由 MathCraft 业务模块持久化。采用该方案是为了支持本地 SQLite、远程数据库和 Windows/macOS 客户端之间的替换，同时避免客户端绑定 Python 包结构或 SDK 内部类型。`backend/src/agents` 作为领域目录名称保留在目标布局中，但实现时必须避免遮蔽 OpenAI SDK 的 `agents` Python 包。
