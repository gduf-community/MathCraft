# ADR-0001：正式知识库作为唯一知识库入口

- 状态：已采纳
- 日期：2026-10-25

## 背景

MathCraft 曾同时装配 DeepTutor 正式知识库模块和出题服务自带的 Chroma/Ollama 轻量链路。两条链路拥有不同的目录、配置、索引生命周期和错误契约，导致前端入口、默认知识库和检索结果可能不一致。

## 决策

1. 以 `MathCraft` 中的正式知识库模块作为唯一知识库实现（2026-10-30 由 `math_q_agent` 合并改名，详见[后端包统一与接口对齐](../design/后端包统一与接口对齐.md)）。
2. 保留 `/api/knowledge-bases/*`、`/ws/knowledge-bases/*` 及正式 RAG provider 多样性，默认 provider 继续为 `llamaindex`。
3. 保留 `/api/generate` 和 `/api/chat`，它们只负责出题编排，检索统一调用 `RAGService`，模型统一调用正式 LLM 配置。
4. 出题请求的 `doc_id` 使用 `raw/` 下的 POSIX 相对路径，并通过 `document_keys` 实施单文档严格检索范围。
5. 删除旧 `/api/kb/*`、Chroma/Ollama 入库、解析、切片、嵌入和检索实现及其专属依赖。
6. 既有运行时数据不自动迁移、不读取、不删除；需要继续使用时由用户通过正式知识库流程重新管理。

## 影响

- 知识库目录、索引版本、任务进度、provider 和模型设置只有一套事实来源。
- 出题服务依赖正式知识库是否已完成索引，并继承其 provider 与配置错误。
- 前端必须先选择正式知识库和其中的 raw 文档。
- 历史 `data/chroma`、`data/uploads` 等运行时目录可以留在本地，但不再参与应用运行。

## 验收标准

- 应用路由中不存在 `/api/kb/*`。
- `/api/generate` 与 `/api/chat` 不导入旧 `config.py`、`vectorstore.py`、`ingestion.py`、`embeddings.py` 或 Chroma/Ollama 依赖。
- 正式 LlamaIndex 索引节点包含 `document_key`，出题检索传递选定文档的 `document_keys`。
- OpenAPI、前端适配器、README、设计文档和术语表描述同一条正式链路。
