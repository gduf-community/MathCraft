# 管理员账号管理与平台信息接口

Type: task
Status: resolved
Triage: ready-for-agent
Blocked by: 01, 02

提供管理员面板所需的账号查询、筛选、创建、显示名称编辑、密码重置、禁用／恢复和平台信息接口。所有管理员同权限；管理员不能兼任教师／学生；禁止禁用最后一个可用管理员。平台信息仅返回基础资料、启用状态、资源汇总和任务运行摘要，不泄露用户私有内容或个人模型密钥。

验收：管理员可管理三类账号和其他管理员；账号角色与登录账号创建后固定；禁用撤销全部会话、恢复不恢复旧会话；平台统计字段和隐私边界符合规范。

规范：../spec.md


实施记录：已完成对应代码与文档同步。完整后端接口测试需要本机 Redis 15 服务可用；当前环境未启动 Redis，因此该项保留环境验证记录。
