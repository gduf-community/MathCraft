Type: task
Status: resolved
Triage: ready-for-agent
Blocked by: 01

将知识库／题库成员权限统一为创建者、可编辑成员、只读成员，改为创建者按登录账号添加、调整和移除成员。保留个人题目、收藏、聊天、组卷记录的账号归属，禁止教师仅凭角色访问其他教师私有记录。学生不能创建新库；历史学生创建的库、文档和索引保留原归属并继续可访问，其他历史成员迁为只读。
