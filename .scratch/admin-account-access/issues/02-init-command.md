# 显式账号初始化命令

Type: task
Status: resolved
Triage: ready-for-agent
Blocked by: 01

提供本地开发和正式部署共用的显式初始化命令，从 .env 读取首个管理员、教师和学生的账号与密码。命令检查配置完整性、三个账号重复和已有角色冲突；首次运行创建缺失账号，重复运行跳过角色匹配的已有账号，不覆盖资料、密码和启用状态。日常服务启动不能触发初始化。

验收：命令可重复执行且幂等；错误不输出密码；配置缺失、重复或角色冲突有明确失败结果；.env.example、README 启动方式和迁移说明同步。
